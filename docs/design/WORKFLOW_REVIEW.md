# Workflow, security and speed review (31 October 2026)

## How it was done

- **Scope:** an independent, read-only review of the user's paths, security and speed, with fresh eyes. Earlier audits, plans, handoffs and session notes were not read.
- **Read:** `README.md`, `docs/SPEC.md` in part, `perch/` (API, private routes, sessions, privacy, egress, export, validator, skills, Scout, MCP, LLM budget, jobs), `web/` (every module), `scripts/ux_walk.py`, `tests/`, `deploy/`, `docker-compose.yml`, `Dockerfile`, `pyproject.toml` and `uv.lock`.
- **Ran:** `scripts/path_measure.py` (new, Playwright, laptop width 1280 px) against the dev server. It ran once per task on 31 October 2026.
- **Also ran:** direct API timings of a brief and of a hand-off, and in-process tests with the test helpers (fake models, SYNTHETIC personas only).
- **Also ran:** a synthetic DOCX zip bomb against `perch.private.inputs`, and a minimal copy of the API's error handler under uvicorn.
- **Also ran:** `pip-audit` over the exported lock file, which reached the advisory database. Model-server journals and the Ollama startup configuration were read, not changed.
- **Not touched:** no server, unit, container or GPU process was restarted or reconfigured. Cloud was never turned on. The demo server was not used.
- **Rate limit hit during the review:** the dev server refused new sessions with 429 after 20 sessions in an hour. Two reviewers share one address. This is evidence for W13.
- **Evidence screenshots:** `build/review/workflow/` (gitignored). Raw path data: `build/paths/paths.json`.
- **Researchers:** named by alias only, PI-4 (A5026494099).

## Checked and fine

- **Session token:** `secrets.token_urlsafe(32)`, sent in a header only, never in a path or query. Sessions expire after 30 idle minutes, swept on access. Each session has its own Scout hub. Isolation is tested (`tests/test_private.py:252`).
- **Rate limiting by address behind the Funnel:** Tailscale Serve sets (overwrites) `X-Forwarded-For` with the connection's source address (`addProxyForwardedHeaders`, `.Set`, in `ipn/ipnlocal/serve.go`). Uvicorn 0.54 trusts loopback and takes it, so a spoofed header cannot reset the limits. That the Funnel source address is the public client's address rests on a code comment (`HandleIngressTCPConn`), so it is UNVERIFIED.
- **CORS:** off unless `PERCH_CORS_ORIGINS` is set. A cross-origin preflight to `/private/session` gets 405. No cookies are used, so CSRF cannot reach session data. A blind form post can only open sessions (see S6).
- **Validation errors:** the `RequestValidationError` handler returns field names only, never input (`perch/api.py:255-261`).
- **Front-end rendering:** every record and model value goes through `textContent`. The only `innerHTML` uses are static SVG (`web/app.js:262`, `web/owl.js:51`). External links pass `safeUrl` (http and https only).
- **HTML export:** `html.escape` everywhere, and only http(s) hrefs (`perch/export.py:256-286`).
- **Citation validator:** layer 1 checks ids, dates and numbers, regenerates once, then flags (`perch/validate.py`). Layer 2 grounding marks unsupported sentences on screen.
- **Scout tool allowlist:** argument shape checks on every call; errors reported by type only; repeated calls reused; turn, token and dollar budgets (`perch/scout/loop.py`, `perch/scout/tools.py:491-511`).
- **MCP server:** same allowlist and `check_arguments`, per-connection call budgets, stdio only, errors by type (`perch/mcp_server.py`).
- **Private-mode gate:** self-hosted adapters and loopback endpoints only. The shared store is opened read-only (`mode=ro`). No audit, timing or Scout log from a session (`perch/private/session.py:131-147`). Core dumps are off (`harden_process`).
- **Model-server logs:** at their current verbosity the Ollama, Clef and model-server journals show token counts, not text (`OLLAMA_DEBUG_LOG_REQUESTS:false`).
- **Anthropic budget:** checked before every call, with a ledger on disk. Unknown prices are charged at the highest listed price. $2.56 of $100 spent.
- **Dependencies:** no other locked package has a known advisory (pip-audit). `torch` was not auditable.
- **Server cost of a poll:** `GET /private/brief` answers in about 11 ms. Scout polls (1.2 s) return about 0.5 KB each. The poll stops when the brief finishes, and stale polls are dropped by generation.
- **No blocking work inside async handlers:** every API handler is a sync `def` and runs on the threadpool.
- **Tab switches:** the path data shows no repeated requests. Each task made one `/private/compare` and one `/private/records` request.
- **Tests:** no test function lacks an assertion, and none is skipped except the Node-dependent web tests when Node is missing (Node is present on this machine).
- **UNVERIFIED:** the Funnel's request-size limit, and the real gzip ratios.
