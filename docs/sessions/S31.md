# S31 — QA cycles (tester, then fixer, up to ten rounds)

Goal: find and fix what the reviews and fixes missed, until a round finds nothing worth fixing. Each round a fresh QA tester tests the dev server end to end as each audience, writes `docs/design/qa/CYCLE_<k>.md`, then a fixer works the must-fix and should-fix items. Stop rule: a round with zero must-fix and zero should-fix, or two rounds in a row with only could-fix, or ten rounds. Started 2026-10-31 21:09 EDT.
